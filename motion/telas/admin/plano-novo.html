Domínio permitido

UazAPI

API não oficial alternativa à Evolution para conexões por QR Code.

Credenciais do servidor

Base URL do servidor, sem barra no final.

Token administrativo (header admintoken). Usado apenas no servidor ao criar instâncias.

Status da configuração Preencha URL e token para ativar.
Pendente
  1. Acesse o site https://uazapi.dev/
  2. Escolha o plano que desejar. Todos os planos liberam todas as funcionalidades; muda apenas a quantidade de conexões de WhatsApp.
  3. Após contratar a UazAPI, clique no seu servidor, ali na direita em Meus Servidores.
  4. Copie o Server URL e o Admin Token e cole acima nos campos.
  5. Depois, para os usuários usarem UazAPI, vá em Planos, edite o plano desejado (ou crie um novo) e selecione UazAPI em API não oficial.
